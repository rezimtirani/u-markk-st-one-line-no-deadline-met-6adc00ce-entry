One single-line joke giving an excuse for missing a deadline: the deadline was going to be hit, but the calendar, the Wi-Fi, and the willpower all filed for leave on the same day.

> I was going to hit the deadline, but my calendar, my Wi-Fi, and my willpower all filed for leave on the same day.

## How it works

`main.py` (Python 3 standard library only) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
